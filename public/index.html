Elyxion

A standalone JavaScript runtime. No Node.js required.

$ curl -fsSL https://raw.githubusercontent.com/xyz-elyxion/elyxion-cli/main/scripts/install.sh | bash
⚡

Zero Dependencies

Built directly on V8 and libuv. No npm, no node_modules — just a single binary.

📦

Built-in Package Manager

elyx init, elyx install, elyx publish — all included.

🌐

Full HTTP Stack

HTTP server, client, and routing. This site is served by Elyxion itself.

🔐

Crypto & Buffers

Hashing, HMAC, and binary data handling built into the runtime.

📂

File System

Read, write, and stream files — all with a familiar Node-compatible API.

🖥️

REPL & CLI

Interactive shell for quick experiments. Perfect for scripting.
